# Grade 1 content sources (Tieng Anh 1 Global Success, u01-u16)

Verified 2026-11-04. The printed book is phonics based: each unit teaches one letter/sound with about 4 key words (U1 Bb, U2 Cc, U3 Aa, U4 Dd, U5 Ch/Ff, U6 Ee, U7 Gg, U8 Hh, U9 Oo, U10 Mm, U11 Uu, U12 Ll, U13 Nn, U14 Tt, U15 Ff, U16 Ww) plus the unit location word and a few extra words. Official words were taken from the sources below; fillers (marked) bring each unit to 10-11 items.

Main source for every unit (per-unit word list, U1-U16): M = https://mytour.vn/vi/blog/bai-viet/tong-hop-tu-vung-tieng-anh-cho-lop-1-va-bai-tap-ap-dung-mytour.html
