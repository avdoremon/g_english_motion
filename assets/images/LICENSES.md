# Image licenses

Every image under `assets/images/` must be covered by a row below.

| File pattern | Source | License |
|---|---|---|
| `assets/images/grade1/*.png` | original placeholder generated by `tools/gen_placeholder_images.py` | project-owned |
| `assets/images/grade2/*.png` | original placeholder generated by `tools/gen_placeholder_images.py` | project-owned |
| `assets/images/grade3/*.png` | original placeholder generated by `tools/gen_placeholder_images.py` | project-owned |
| `assets/images/grade4/*.png` | original placeholder generated by `tools/gen_placeholder_images.py` | project-owned |
| `assets/images/grade5/*.png` | original placeholder generated by `tools/gen_placeholder_images.py` | project-owned |

These are temporary placeholder word cards: a pastel background and a neutral
shape derived from a hash of the word, never a letter (a letter would let a
child who knows the alphabet answer "which picture is ...?" without
recognising the picture). Real artwork will replace them (keep the same file
names) and its source and license must be recorded here.
